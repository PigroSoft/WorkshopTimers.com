# Fonts

Seven fonts are embedded in `index.html` as base64 WOFF2 files, each cut down to the characters the app uses. All seven are under the [SIL Open Font License 1.1](OFL.txt), which allows embedding, modifying and redistributing them, including in commercial software, as long as the licence and copyright notices travel with them. None of them uses a Reserved Font Name.

These fonts are not covered by the MIT licence in [LICENSE](LICENSE); they stay under the OFL.

| Font | Used for | Copyright |
|---|---|---|
| Roboto Medium | Squiggle theme, Roboto font option | Copyright 2011 The Roboto Project Authors ([googlefonts/roboto-classic](https://github.com/googlefonts/roboto-classic)) |
| Jost Bold | Clouds theme, Jost font option | Copyright 2020 The Jost Project Authors ([indestructible-type/Jost](https://github.com/indestructible-type/Jost)) |
| Michroma | Stars theme, Michroma font option | Copyright 2011 The Michroma Project Authors ([googlefonts/Michroma-font](https://github.com/googlefonts/Michroma-font)) |
| Bellefair | Aurora and Searchlight labels | Copyright 2015 The Bellefair Project Authors ([shinntype/bellefair](https://github.com/shinntype/bellefair)) |
| Bitcount Grid Single ExtraLight | Searchlight digits | Copyright 2024 The Bitcount Project Authors ([petrvanblokland/TYPETR-Bitcount](https://github.com/petrvanblokland/TYPETR-Bitcount)) |
| Modak | Gradient theme, Modak font option | Copyright (c) 2014, Ek Type |
| Fraunces | Ocean theme, Fraunces font option | Copyright 2020 The Fraunces Project Authors ([undercasetype/Fraunces](https://github.com/undercasetype/Fraunces)) |

Other font options (Helvetica, Georgia, Avenir, Menlo and so on) are not shipped with the app; they name fonts that may already be installed on the viewer's computer and fall back to similar system fonts when they aren't.

Any font you upload in Settings stays in your browser and is never part of the app.

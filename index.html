Use it as an app (Mac & PC)

Install WorkshopTimers.com so it opens in its own window, with no tabs or address bar, and launches like any native app.

Mac · Safari: File menu → Add to Dock → Add. Launch it from your Dock.
Mac & PC · Chrome: click the install icon (monitor with a down-arrow) at the right edge of the address bar → Install. Or ⋮ menu → Cast, Save & Share → Install page as app.
PC · Edge: ⋯ menu → Apps → Install this site as an app.

Once it's open, the timer runs entirely on your device, with no internet needed to keep time. Perfect for a projector or TV.
